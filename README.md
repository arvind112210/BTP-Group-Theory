# Visualizing Sylow's Theorems using GAP and Web Technologies

**Status:** Active Development (Expected Completion: Nov 2026)
**Context:** Bachelor's Thesis Project at IIT Guwahati

### Overview
This project aims to translate abstract algebraic computations into intuitive, clickable educational models. It utilizes GAP (Groups, Algorithms, Programming)
as an algorithmic engine to compute subgroup lattices, normalizers, and conjugacy classes for complex mathematical groups. 

### Tech Stack
* **Backend Engine:** GAP
* **Frontend Visualization:** SVG, JavaScript

### Roadmap
- [x] Initial GAP engine setup and core algorithmic framework.
- [ ] Integration of embedded JavaScript for real-time group actions.
- [ ] Dynamic rendering of Hasse diagrams using zero-dependency SVG.
